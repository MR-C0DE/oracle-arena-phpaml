# Security policy

PHPAML is pre-stable. Report vulnerabilities privately through GitHub Security Advisories. The latest release and current `main` branch are supported; older pre-releases are not. Critical reports should be acknowledged within 72 hours and assessed within 7 days.

Do not publish exploit details or secrets in issues. Include the affected version, impact, reproduction steps, and a minimal proof of concept, and test only systems you are authorized to test.
