# Contributing to the PHPAML Template

Thank you for improving the first project generated for PHPAML users.

Search existing issues first. Use a private GitHub Security Advisory for vulnerabilities. Never include credentials, private URLs, personal data, generated dependencies, or unredacted environment files.

Keep template changes small and compatible with the supported Framework and CLI releases. Add or update smoke tests and documentation, run the repository test suite, and open a pull request explaining the generated-project impact and verification. Discuss structural changes in an issue first.

English is the primary public language; keep French documentation aligned when shared concepts change. Contributions are licensed under the [MIT License](LICENSE).

## Français

Les améliorations ciblées du projet généré sont bienvenues. Vérifiez la compatibilité CLI/Framework, exécutez les tests et n’incluez aucun secret. Toute contribution est distribuée sous licence MIT.
